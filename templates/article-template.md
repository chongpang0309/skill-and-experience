# 文章结构模板

> 适用：公众号长文  
> 类型：AI工具测评/教程  
> 字数建议：1500-3000字

---

## 模板一：工具测评类

### 文章结构

```
【标题】
主标题：数字/对比 + 核心卖点
副标题：补充说明/吸引点击

示例：
主标题：「Claude 3 实测：这5个功能让我放弃了ChatGPT」
副标题：「深度体验报告，包含详细对比和使用场景」
```

### 正文结构

**1. 引言（200-300字）**
- 钩子：痛点/热点/数据
- 背景：为什么关注这个工具
- 预告：文章将解决什么问题

```模板：
你有没有遇到过 [具体痛点]？
最近 [热点事件/数据]，让我开始关注 [工具名称]。
经过 [时长] 的深度使用，我发现 [核心发现]。
今天这篇文章，我将从 [维度1]、[维度2]、[维度3] 三个维度，
带你全面了解这个工具是否值得使用。
```

**2. 工具简介（200-300字）**
- 是什么：一句话定义
- 背景：开发团队/公司
- 定位：适合什么人群
- 价格：免费/付费方案

**3. 核心功能详解（800-1200字）**
- 分 3-5 个点介绍
- 每个点包含：
  - 功能名称
  - 使用场景
  - 操作演示（截图/录屏）
  - 实际效果

```模板：
### 功能1：[功能名称]

[功能描述]

**适用场景：**
- 场景1
- 场景2

**操作步骤：**
1. 步骤1
2. 步骤2
3. 步骤3

**实际效果：**
[截图 + 说明]

**优缺点：**
- ✅ 优点
- ❌ 缺点
```

**4. 对比分析（300-500字）**
- 与竞品对比表格
- 各自优劣势
- 选择建议

```模板：
| 维度 | 工具A | 工具B | 工具C |
|------|-------|-------|-------|
| 价格 | | | |
| 功能 | | | |
| 易用性 | | | |
| 适合人群 | | | |

**选择建议：**
- 如果你 [情况1]，选择 [工具A]
- 如果你 [情况2]，选择 [工具B]
```

**5. 使用技巧（300-500字）**
- 3-5 个实用技巧
- 提示词模板（如适用）
- 避坑指南

**6. 总结与建议（200-300字）**
- 核心观点回顾
- 适合人群总结
- 下一步行动建议

**7. 互动引导（50-100字）**
- 提问引发讨论
- 引导关注/转发
- 预告下期内容

## 模板二：教程类

### 文章结构

```
【标题】
「如何用 [工具] [达成效果]：[时间/难度] 完整指南」

示例：
「如何用AI一天写完周报：1小时上手完整教程」
```

### 正文结构

**1. 引言（150-200字）**
- 痛点：描述问题
- 方案：预告解决方法
- 收益：学完能获得什么

```模板：
写周报是不是你最头疼的事情之一？
每次都要花 [时间]，还要担心写不好。
今天我要分享一个方法，让你 [时间] 内完成高质量的周报，
而且老板看了都点赞。
这个方法我已经用了 [时长]，亲测有效。
```

**2. 前置准备（100-150字）**
- 需要的工具
- 准备工作
- 适用条件

**3. 核心步骤（1000-1500字）**
- 分步骤详细讲解
- 每步配截图
- 关键细节标注

```模板：
### Step 1: [步骤名称]

**目标：** [这步要做什么]

**操作：**
1. [具体操作]
2. [具体操作]
3. [具体操作]

**截图：**
[图片]

**注意事项：**
- [注意点1]
- [注意点2]
```

**4. 效果展示（200-300字）**
- 前后对比
- 时间节省统计
- 质量提升说明

**5. 进阶技巧（200-300字）**
- 优化方法
- 常见问题解决
- 扩展应用

**6. 总结（100-150字）**
- 核心步骤回顾
- 行动号召

## 模板三：经验分享类

### 文章结构

```
【标题】
「[时间/身份] 的 [工具] 使用心得：[核心收获]」

示例：
「20年开发者的AI工具使用心得：效率提升10倍的秘密」
```

### 正文结构

**1. 个人背景（150-200字）**
- 我是谁
- 使用背景
- 为什么分享

**2. 使用历程（300-500字）**
- 什么时候开始用
- 经历了哪些阶段
- 踩过哪些坑

**3. 核心心得（800-1200字）**
- 3-5 条核心经验
- 每条配具体案例
- 可操作的建议

```模板：
### 心得1: [心得标题]

[详细说明]

**我的案例：**
[具体例子]

**给你的建议：**
1. [建议1]
2. [建议2]
```

**4. 工具推荐（300-400字）**
- 常用工具清单
- 选择理由
- 使用场景

**5. 总结与展望（200-300字）**
- 核心观点
- 未来计划
- 互动邀请

## 小红书图文模板

### 封面设计
- 尺寸：3:4（推荐 1242×1660）
- 标题：大字、醒目、不超过10个字
- 配色：统一风格，高对比度
- 元素：图标、截图、装饰

### 内容页结构（3-5页）

**第1页：封面**
- 大标题
- 副标题/痛点
- 个人标识

**第2页：问题/痛点**
- 场景描述
- 共鸣点
- 引导继续看

**第3-4页：解决方案**
- 步骤1/要点1
- 步骤2/要点2
- 配截图/图示

**第5页：总结/行动**
- 核心结论
- 行动建议
- 引导互动

### 文案公式

```
标题：痛点 + 解决方案 + 效果

正文：
[痛点描述] 😫
[解决方案] 💡
[详细步骤]
1. [步骤1]
2. [步骤2]
3. [步骤3]
[效果展示] ✅
[行动号召] 👇

话题：#AI工具 #效率提升 #职场技能
```

## 通用写作技巧

### 标题公式

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字法 | 数字 + 核心内容 | 「5个AI工具让效率翻倍」 |
| 对比法 | A vs B | 「Claude vs GPT-4 深度对比」 |
| 场景法 | 场景 + 解决方案 | 「如何用AI一天写完周报」 |
| 揭秘法 | 身份 + 秘密 | 「资深开发者的AI工具箱」 |
| 效果法 | 方法 + 效果 | 「这个方法让我早下班2小时」 |

### 开头钩子

1. **痛点型**：「你有没有遇到过...」
2. **数据型**：「据统计，90%的人...」
3. **故事型**：「上周，我遇到了一件事...」
4. **反转型**：「很多人以为...其实...」
5. **热点型**：「最近ChatGPT发布了新功能...」

### 结尾模板

```
总结一下：
1. [要点1]
2. [要点2]
3. [要点3]

如果你 [目标人群]，建议 [行动建议]。

你觉得 [互动问题]？欢迎在评论区分享。

记得点赞、收藏、关注，下期我们聊 [预告内容]。
```
