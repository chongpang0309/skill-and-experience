# Skill and Experience

个人技能与经验知识库

## 目录结构

```
.
├── README.md                 # 本文件
├── skills/                   # 技能文档
│   ├── programming/          # 编程技能
│   ├── tools/                # 工具使用
│   ├── languages/            # 语言学习
│   └── ...
├── experiences/              # 经验记录
│   ├── projects/             # 项目经验
│   ├── problems/             # 问题解决方案
│   └── insights/             # 心得体会
├── notes/                    # 随手笔记
├── templates/                # 文档模板
└── archive/                  # 归档文件
```

## 使用说明

- **skills/**: 系统化的技能学习笔记，按类别组织
- **experiences/**: 实际项目经验和问题解决记录
- **notes/**: 临时笔记，后续需要整理到对应目录
- **templates/**: 常用文档模板

## 命名规范

- 文件使用小写字母和连字符： `my-skill-note.md`
- 子目录按主题分类
- 日期格式：YYYY-MM-DD
